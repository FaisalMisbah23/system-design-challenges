# Part 1: Toolkit check

This part checks the smallest useful project contract: the repository can read a Node.js version, reject malformed input, compare the version with a minimum, and test the current machine. Run it with:

```sh
node --test challenges/challenge-0-repository-setup/part-1-toolkit-check/check.test.js
```
