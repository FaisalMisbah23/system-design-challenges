# Challenge 0: Repository setup

## 101 glossary

- **Node.js:** A program that runs JavaScript outside a web browser.
- **npm:** Node.js's package manager and the command-line tool used to run project scripts.
- **Test runner:** A tool that finds tests, runs them, and reports which checks passed or failed.
- **CI:** Continuous integration: an automated service that tests changes whenever code is pushed or a pull request is opened.
- **Container and image:** An image is a packaged filesystem and startup recipe; a container is a running instance of that image.
